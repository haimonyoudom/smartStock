# SmartStock API Contract

This contract describes the REST API for SmartStock. IDs are strings, prices
are amounts in USD, and date-time values use ISO 8601 format.

## 1. Resources and fields

### User

| Field | Type | Rules |
| :--- | :--- | :--- |
| `id` | string | Required in responses; system-generated and unique |
| `name` | string | Required; 2–100 characters |
| `email` | string | Required; valid email, unique |
| `role` | enum | Required; `OWNER` or `CASHIER` |
| `active` | boolean | Required; defaults to `true` |

Passwords are accepted only by the login request and are never returned in a
User response.

### Product

| Field | Type | Rules |
| :--- | :--- | :--- |
| `id` | string | Required in responses; system-generated and unique |
| `name` | string | Required; 2–100 characters |
| `sku` | string | Required; 3–20 alphanumeric characters or hyphens, unique |
| `sellingPrice` | number | Required; greater than `0`, maximum 2 decimal places |
| `stockQuantity` | integer | Required; whole number, minimum `0` |
| `lowStockThreshold` | integer | Required; whole number, minimum `0` |
| `active` | boolean | Required; defaults to `true` |

### Sale

Sales are stored separately from their sale items. A sale response contains
the fields below; use `/saleItems?saleId=:saleId` to retrieve its items.

| Field | Type | Rules |
| :--- | :--- | :--- |
| `id` | string | Required in responses; system-generated and unique |
| `saleDate` | string | Required; ISO 8601 date-time |
| `totalAmount` | number | Required; calculated server-side, greater than `0`, maximum 2 decimal places |
| `createdBy` | string | Required; must reference an existing User |

### SaleItem

| Field | Type | Rules |
| :--- | :--- | :--- |
| `id` | string | Required in responses; system-generated and unique |
| `saleId` | string | Required; must reference an existing Sale |
| `productId` | string | Required; must reference an existing active Product |
| `quantity` | integer | Required; whole number from `1` to `100` |
| `unitPrice` | number | Required in responses; copied from Product, greater than `0`, maximum 2 decimal places |
| `subtotal` | number | Required in responses; calculated as `quantity * unitPrice`, maximum 2 decimal places |

### StockMovement

| Field | Type | Rules |
| :--- | :--- | :--- |
| `id` | string | Required in responses; system-generated and unique |
| `productId` | string | Required; must reference an existing Product |
| `userId` | string | Required; must reference the User making the change |
| `movementType` | enum | Required; `SALE` or `ADJUSTMENT` |
| `quantityChange` | integer | Required; non-zero. Negative for a sale or deduction, positive for restock |
| `reason` | string | Required; 2–100 characters |
| `createdAt` | string | Required; ISO 8601 date-time |

## 2. Request DTOs

### LoginDto

| Field | Type | Rules |
| :--- | :--- | :--- |
| `email` | string | Required; valid email |
| `password` | string | Required; 8–100 characters |

### CreateProductDto

Contains `name`, `sku`, `sellingPrice`, `stockQuantity`, `lowStockThreshold`,
and optional `active`. The `id` is generated by the server.

### UpdateProductDto

Contains any subset of the CreateProductDto fields. The request must contain
at least one field.

### AdjustStockDto

| Field | Type | Rules |
| :--- | :--- | :--- |
| `quantityChange` | integer | Required; non-zero |
| `reason` | string | Required; 2–100 characters |

The resulting product stock cannot be negative.

### CreateSaleDto

| Field | Type | Rules |
| :--- | :--- | :--- |
| `items` | array | Required; at least one item |
| `items[].productId` | string | Required; existing active Product |
| `items[].quantity` | integer | Required; whole number from `1` to `100` |

The server obtains prices from the products, calculates sale items and the
total, deducts stock, and creates the related stock movements.

## 3. Endpoint summary

| Method | Path | Request body | Success response | Error statuses | Authentication |
| :--- | :--- | :--- | :--- | :--- | :--- |
| POST | `/auth/login` | `LoginDto` | `200 OK` — `{ accessToken, user }` | `400 Bad Request`; `401 Unauthorized` | Public |
| GET | `/users` | None | `200 OK` — `User[]` | `401 Unauthorized`; `403 Forbidden` | OWNER |
| GET | `/users/:id` | None | `200 OK` — `User` | `401 Unauthorized`; `404 Not Found` | OWNER |
| GET | `/products` | None | `200 OK` — `Product[]` | `401 Unauthorized` | OWNER or CASHIER |
| GET | `/products/low-stock` | None | `200 OK` — `Product[]` | `401 Unauthorized` | OWNER or CASHIER |
| GET | `/products/:id` | None | `200 OK` — `Product` | `400 Bad Request`; `401 Unauthorized`; `404 Not Found` | OWNER or CASHIER |
| POST | `/products` | `CreateProductDto` | `201 Created` — `Product` | `400 Bad Request`; `401 Unauthorized`; `403 Forbidden`; `409 Conflict` | OWNER |
| PATCH | `/products/:id` | `UpdateProductDto` | `200 OK` — `Product` | `400 Bad Request`; `401 Unauthorized`; `403 Forbidden`; `404 Not Found`; `409 Conflict` | OWNER |
| DELETE | `/products/:id` | None | `204 No Content` | `401 Unauthorized`; `403 Forbidden`; `404 Not Found` | OWNER |
| POST | `/products/:id/adjust-stock` | `AdjustStockDto` | `200 OK` — `Product` | `400 Bad Request`; `401 Unauthorized`; `403 Forbidden`; `404 Not Found`; `422 Unprocessable Entity` | OWNER or CASHIER |
| GET | `/sales` | None | `200 OK` — `Sale[]` | `401 Unauthorized` | OWNER or CASHIER |
| GET | `/sales/:id` | None | `200 OK` — `Sale` | `400 Bad Request`; `401 Unauthorized`; `404 Not Found` | OWNER or CASHIER |
| POST | `/sales` | `CreateSaleDto` | `201 Created` — `Sale` | `400 Bad Request`; `401 Unauthorized`; `409 Conflict` | OWNER or CASHIER |
| GET | `/saleItems` | None | `200 OK` — `SaleItem[]` | `401 Unauthorized` | OWNER or CASHIER |
| GET | `/saleItems?saleId=:saleId` | None | `200 OK` — `SaleItem[]` | `400 Bad Request`; `401 Unauthorized`; `404 Not Found` | OWNER or CASHIER |
| GET | `/stockMovements` | None | `200 OK` — `StockMovement[]` | `401 Unauthorized` | OWNER or CASHIER |
| GET | `/stockMovements?productId=:productId` | None | `200 OK` — `StockMovement[]` | `400 Bad Request`; `401 Unauthorized`; `404 Not Found` | OWNER or CASHIER |

Collection endpoints return an empty array when there are no matching
records. The `saleItems` collection is normalized rather than nested inside
the Sale resource.

## 4. Authentication and roles

| Route group | Login required | Allowed roles |
| :--- | :--- | :--- |
| `/auth/login` | No | Public |
| `GET /users*` | Yes | `OWNER` |
| Product reads | Yes | `OWNER`, `CASHIER` |
| Product create, update, delete | Yes | `OWNER` |
| Stock adjustment | Yes | `OWNER`, `CASHIER` |
| Sales and sale-item reads | Yes | `OWNER`, `CASHIER` |
| Create sale | Yes | `OWNER`, `CASHIER` |
| Stock-movement reads | Yes | `OWNER`, `CASHIER` |
